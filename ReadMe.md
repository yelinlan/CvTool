# CvTool - 文件加解密工具

## 这是什么？

`CvTool` 是一个简单的文件加密工具，可以将文件加密后复制到剪贴板，或者从剪贴板解密文件。适合在不同设备间安全传输文件。

## 适用场景

- 需要通过聊天工具（微信、QQ等）传输敏感文件
- 在不安全的网络环境下传输文件
- 临时备份重要文件到剪贴板

## 快速开始

### 方式一：右键菜单使用（推荐）

1. 运行 `java -jar CvTool.jar` 选择对应功能生成注册表文件
2. 双击生成的注册表文件导入系统
3. 右键文件选择"toText"加密，右键文件夹选择"toFile"解密

### 方式二：命令行使用

```bash
# 加密文件并复制到剪贴板
java -jar CvTool.jar 文件路径 0

# 从剪贴板解密并保存文件
java -jar CvTool.jar 目标文件夹路径 1
```


## 核心特性

- 🔒 AES加密，每小时自动更换密钥
- 📋 直接与系统剪贴板交互
- 🖱️ 支持右键菜单一键操作
- ⚡ 单文件小于20MB限制
